# Табель, авансові податки та датовані податки — приймання

29.10.2026. Вихідний коміт: 22eec5e. Робоча база: 066.
**Пакет реалізований і перевірений у наведеному обсязі; повне закриття
трьох напрямів і всього блоку 13 не оголошується.**

## Реалізовано

1. Окремий запит виправлення звичайних робочих хвилин і незалежне погодження.
   Нова версія зарплати відтворює історичні ставки, мінімальну гарантію,
   податки й бухгалтерську різницю. Первісний табель та платежі незмінні.
   Перегляд табеля показує первісні й ефективні хвилини окремо.
   Переплата погашається підтвердженим банківським поверненням, без
   автоматичного утримання. До первісного проведення створюється повна
   нова проводка. Повторні виправлення та історичний перегляд перевірені.
2. Підтверджені авансові ПДФО, ВЗ та ЄСВ зараховуються за договором і місяцем
   у місячні податкові залишки та ліміт доплати. Жодної додаткової проводки
   заліку не створюється. До нарахування платежі видно окремо; фактична
   переплата не приховується. Історичні дати й сторнування збережені.
   Додані API реєстрації/перегляду/сторнування авансових податків і SQL-захист
   історії. Snapshot працівника перевіряється проти справжнього договору.
3. Місячний податковий розрахунок розподіляє підтверджений дохід за датами
   ставок/профілів/правил. Зарплатні зрізи формуються на межах податкових
   правил. Відпускні/лікарняні беруть датовані джерела, компенсація — дату
   розрахунку, доплати — документовану дату. ПСП та межі ЄСВ застосовуються
   один раз за місяць працівника, включно з кількома договорами. Результати
   мають незмінні джерела та завершальну мітку, яка забороняє пізні вставки.

## Перевірки

Прогони перетинаються; кількості не слід додавати як унікальні тести.

- Фінальний цільовий PostgreSQL-прогін: **49 passed** — авансові податки,
  табель, датовані податки, середня зарплата, місячні розрахунки, API,
  історичні залишки та міграція.
- Фінансова регресія: **41 passed** — автоматичний аванс, відпустки,
  лікарняні та податки за кількома договорами.
- Додаткова перевірка непроведеної зарплати й відпусток: **19 passed**.
- API авансових податків і табеля: **10 passed**.
- Відтворення табеля, джерело авансу та API: **19 passed**.
- Захист датованих податкових результатів та міграція: **7 passed**.
- Бази для перевірок ізольовані, видалені; вихідна база під час тестів незмінна.
- Перед робочою міграцією збережено перевірений custom-format backup.
  Після 064 → 066 перевірено старі колонки **201 таблиці**: кількості та
  SHA256 незмінні. Схема перевіряється Alembic.

## Що ще не закривається цим пакетом

- Зміна самих дат вже використаного лікарняного разом із новим медичним
  документом: чинне коригування лікарняного перевизначає його фінансові
  джерела, а не календар первісної заявки. Табель не обходить діючу відсутність.
- Виправлення нічних, понаднормових і вихідних годин із повторним розрахунком
  відповідних доплат. Якщо така доплата є на змінювану дату, звичайний
  перерахунок табеля блокується, щоб не залишити неправильну стару суму.
- Непідтверджені/довільні ручні коригування доходу не діляться за датами
  автоматично; для них потрібен окремий погоджений розподіл джерела.
- Регламентована звітність, КЕП/подання та розділення ролей PostgreSQL мають
  окреме приймання. Цей пакет не закриває їх.
